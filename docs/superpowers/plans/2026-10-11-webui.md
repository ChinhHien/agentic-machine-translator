# UI web polyglot-lc — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dựng một UI web chạy local trong `webui/` để điều khiển và theo dõi các lượt
dịch của `polyglot-lc`, xem lại lịch sử lượt chạy, và quản lý cấu hình, glossary, skills.

**Architecture:** Một server Python chỉ dùng thư viện chuẩn bind `127.0.0.1`, điều phối
mỗi lượt dịch như một **tiến trình con CLI** với `LOGS_DIR` và `--out` riêng; UI đọc tiến
độ bằng cách polling file JSONL sự kiện mà pipeline đã ghi sẵn. Frontend là HTML/CSS/JS
thuần, không npm, không bước build, không webfont.

**Tech Stack:** Python 3.11+ (`http.server`, `ThreadingHTTPServer`, `subprocess`,
`json`, `csv`), pytest, HTML/CSS/JS thuần. **Không thêm dependency nào.**

**Spec:** [docs/superpowers/specs/2026-10-11-webui-design.md](../specs/2026-10-11-webui-design.md)

**Về commit:** mỗi task kết thúc bằng một commit, đúng như quy trình. Việc thực thi plan
này chỉ bắt đầu sau khi người dùng chọn cách thực thi, và lựa chọn đó là thứ cho phép các
commit theo từng task.

## Global Constraints

Copy nguyên văn từ spec; mọi task đều ngầm bao gồm mục này.

- **Không thêm dependency.** `[project].dependencies` trong `pyproject.toml` không được
  đổi. `webui/` chỉ dùng thư viện chuẩn.
- **`webui/*.py` không được `import polyglot_lc`.** Ngoại lệ duy nhất: `webui/probe.py`,
  và nó chỉ được chạy như một tiến trình con, không bao giờ được import vào server.
  Lý do: `config.py` gọi `load_dotenv()` lúc import và `load_dotenv` không ghi đè biến đã
  có, nên server nạp `.env` sẽ làm tiến trình con bỏ qua `.env`.
- **Bind cứng `127.0.0.1`**, cổng mặc định `8787`. Không có tham số đổi thành `0.0.0.0`.
- **Bí mật không bao giờ bị chạm.** Với mọi tên biến chứa `KEY`, `TOKEN`, `SECRET` hoặc
  `PASSWORD` (không phân biệt hoa thường): không đọc giá trị, không trả về trong bất kỳ
  response nào, không ghi/sửa/xoá dòng đó trong `.env`. Chỉ được trả `"set"` / `"unset"`.
- **Whitelist cấu hình sửa được** (đúng các tên này, không thêm bớt):
  `CHUNK_MAX_TOKENS`, `CHUNK_OVERLAP_TOKENS`, `MAX_CONCURRENCY`, `CRITIC_THRESHOLD`,
  `REFINE_ROUNDS`, `REFINE_MIN_SCORE`, `RB_TOP_K`, `UNIFIED_PLANNER`, `ADAPTIVE_QUALITY`,
  `FAST_PATH_MAX_COMPLEXITY`, `FAST_PATH_MIN_SCORE`, `FAST_PATH_SKIP_LLM_VERIFY`,
  `CONSISTENCY_CHECK`, `CONSISTENCY_MAX_PATCHES`, `PARTIAL_OUTPUT`, `RESUME`, `PDF_EXTRACTOR`,
  `LLM_MOCK`.
- **Chỉ hiển thị, không sửa được:** `LOGS_DIR`, `SKILLS_DIR`, `REASONING_BANK_PATH`,
  `CHECKPOINT_DIR`.
- **Mọi `POST`/`PUT` kiểm `Origin`**: thiếu, hoặc khác `http://127.0.0.1:<port>` /
  `http://localhost:<port>` → `403`.
- **Test nằm ở `tests/`,** đặt tên `test_webui_<phần>.py`. Không có file `.md` nào trong

  `sys.path`.
- **Đường dẫn theo lượt chạy:** log ở `logs/webui/<run_id>/`, kết quả ở
  `output/webui/<run_id>/`. Glossary do UI quản lý ở `glossaries/` (thư mục mới).
- **Token thiết kế** (không được đổi giá trị): `--paper #F2F3F5`, `--panel #FFFFFF`,

- **Không sửa `src/polyglot_lc/`.** Nếu gặp chặn kỹ thuật buộc phải sửa, dừng và hỏi.

**Files:**
- Create: `webui/store.py` (chỉ `ConfigStore` ở task này)

**Interfaces:**
- Consumes: `webui.paths.safe_child`.
- Produces:
  - `webui.store.EDITABLE_KEYS: tuple[str, ...]`, `READONLY_KEYS: tuple[str, ...]`
  - `webui.store.is_secret(name: str) -> bool`
  - `webui.store.ConfigStore(root: Path, env_path: Path)` với:
    - `save(values: dict[str, Any]) -> tuple[list[str], list[dict[str, str]]]`

**Phân chia trách nhiệm:** `ConfigStore` chỉ sở hữu việc **đọc/ghi `.env` an toàn**.
Việc phân loại `source` (env / dotenv / default) thuộc về `probe.py`, vì chỉ ở đó mới
quan sát được `os.environ` thật; `ConfigStore` chạy trong tiến trình server nên không thể
tự biết một giá trị đến từ môi trường hay từ default.

```python
# tests/test_webui_store.py
from pathlib import Path

import pytest

from webui.store import EDITABLE_KEYS, ConfigStore, is_secret

ENV = (
    "# cấu hình mẫu\n"
    "CHUNK_MAX_TOKENS=700\n"
    "\n"
    "TRANSLATOR_API_KEY=sk-CANARY-DO-NOT-LEAK\n"
    "SOME_UNRELATED=1\n"
)


def _store(tmp_path, text=ENV):
    p = tmp_path / ".env"
    p.write_bytes(text.encode("utf-8"))
    return ConfigStore(tmp_path, p)


def test_env_keys_lists_names_only(tmp_path):
    s = _store(tmp_path)
    assert s.env_keys() == {"CHUNK_MAX_TOKENS", "TRANSLATOR_API_KEY", "SOME_UNRELATED"}


def test_no_secret_value_is_ever_returned(tmp_path):
    s = _store(tmp_path)
    blob = repr(s.env_keys())
    assert "sk-CANARY-DO-NOT-LEAK" not in blob
    assert is_secret("TRANSLATOR_API_KEY") and is_secret("x_token") and is_secret("DB_PASSWORD")
    assert not is_secret("CHUNK_MAX_TOKENS")


def test_save_preserves_comments_blank_and_foreign_lines(tmp_path):
    s = _store(tmp_path)
    saved, rejected = s.save({"CHUNK_MAX_TOKENS": 900})
    text = (tmp_path / ".env").read_text(encoding="utf-8")
    assert saved == ["CHUNK_MAX_TOKENS"] and rejected == []
    assert "# cấu hình mẫu" in text and "SOME_UNRELATED=1" in text
    assert "CHUNK_MAX_TOKENS=900" in text and "700" not in text
    assert "sk-CANARY-DO-NOT-LEAK" in text  # dòng key bị giữ nguyên, không bị sửa


def test_save_appends_missing_key_and_rejects_unknown(tmp_path):
    s = _store(tmp_path)
    saved, rejected = s.save({"PARTIAL_OUTPUT": 1, "NOT_A_KEY": 1})
    assert saved == ["PARTIAL_OUTPUT"]
    assert rejected == [{"key": "NOT_A_KEY", "reason": "not editable"}]
    assert (tmp_path / ".env").read_text(encoding="utf-8").rstrip().endswith("PARTIAL_OUTPUT=1")


def test_save_preserves_crlf_line_endings(tmp_path):
    s = _store(tmp_path, ENV.replace("\n", "\r\n"))
    s.save({"CHUNK_MAX_TOKENS": 900})
    raw = (tmp_path / ".env").read_bytes()
    assert b"CHUNK_MAX_TOKENS=900\r\n" in raw
    assert b"\n" not in raw.replace(b"\r\n", b"")  # không có LF trần


def test_save_rejects_a_secret_even_if_someone_lists_it(tmp_path):
    s = _store(tmp_path)
    saved, rejected = s.save({"MY_API_KEY": "x"})
    assert saved == [] and rejected == [{"key": "MY_API_KEY", "reason": "secret"}]
```

```python
# tests/test_webui_probe.py
import json
import subprocess
import sys
from pathlib import Path

from webui.paths import REPO_ROOT

PROBE = REPO_ROOT / "webui" / "probe.py"


def _run(*args, cwd=REPO_ROOT, env=None):
    return subprocess.run(
        [sys.executable, str(PROBE), *args],
        capture_output=True, text=True, cwd=cwd, env=env,
    )


def test_config_lists_whitelist_and_no_secret(tmp_path):
    from webui.store import EDITABLE_KEYS, READONLY_KEYS

    proc = _run("--config")
    assert proc.returncode == 0, proc.stderr
    data = json.loads(proc.stdout)
    assert set(data["values"]) == set(EDITABLE_KEYS) | set(READONLY_KEYS)
    assert set(data["sources"]) == set(data["values"])
    assert not [k for k in data["values"] if "KEY" in k.upper()]


def test_plan_chunk_count_matches_the_real_chunker(tmp_path):
    doc = tmp_path / "d.md"
    doc.write_text("# T\n\n" + "một câu. " * 400, encoding="utf-8")

    proc = _run("--plan", str(doc), "--src", "vi", "--tgt", "en")
    assert proc.returncode == 0, proc.stderr
    plan = json.loads(proc.stdout)

    from polyglot_lc.ingest import load_document
    from polyglot_lc.segment.chunker import chunk_document

    expected = len(chunk_document(load_document(doc), model="mock-model"))
    assert plan["chunks"] == expected
    assert plan["output_path"].endswith(".en.md")


def test_plan_on_a_missing_file_exits_nonzero_with_stderr_only():
    proc = _run("--plan", "does-not-exist.md", "--src", "vi", "--tgt", "en")
    assert proc.returncode != 0
    assert proc.stdout.strip() == ""
    assert proc.stderr.strip()
```

### Task 4: RunsStore, SkillsStore, GlossaryStore

**Files:**
- Modify: `webui/store.py`
- Modify: `tests/test_webui_store.py`

**Interfaces:**
- Consumes: `webui.paths.safe_child`.
- Produces:
  - `webui.store.RunRecord` — dataclass: `run_id, started, status, file, src, tgt, domain,
    chunks, exit_code, output_path, mock, pid, command, note`.
    `status` ∈ `"running" | "done" | "failed" | "stopped"`.
  - `webui.store.RunsStore(root: Path)` — `root` là `logs/webui`:
    `dir_for(run_id) -> Path`, `write_record(rec) -> None`, `read_record(run_id) -> RunRecord | None`,
    `list_records() -> list[RunRecord]` (mới nhất trước),
    `log_path(run_id) -> Path | None` (file `run_*.jsonl` mới nhất trong thư mục lượt),
    `read_events(run_id, after: int) -> tuple[list[dict], int, int]` trả
    `(events, next_index, malformed_count)`.
  - `webui.store.SkillsStore(root: Path)` — `list_skills() -> list[dict]`,
    `get_skill(pair, domain) -> dict | None`, `history(pair, domain) -> list[dict]`.
  - `webui.store.GlossaryStore(root: Path)` — `list_files() -> list[dict]`,
    `read(name) -> list[list[str]]`, `write(name, pairs) -> None`.

```python
# thêm vào tests/test_webui_store.py
import json

from webui.store import GlossaryStore, RunRecord, RunsStore, SkillsStore


def test_run_record_round_trip_and_order(tmp_path):
    s = RunsStore(tmp_path)
    for rid, ts in (("b", 2.0), ("a", 1.0)):
        s.write_record(RunRecord(run_id=rid, started=ts, status="done", file="f.md",
                                 src="en", tgt="vi", domain="tech", chunks=3,
                                 exit_code=0, output_path="o.md", mock=True, pid=None,
                                 command=["x"], note=""))
    assert [r.run_id for r in s.list_records()] == ["b", "a"]
    assert s.read_record("a").chunks == 3
    assert s.read_record("missing") is None


def test_read_events_counts_malformed_lines(tmp_path):
    s = RunsStore(tmp_path)
    d = s.dir_for("r1")
    d.mkdir(parents=True)
    (d / "run_20260101_000000.jsonl").write_text(
        '{"step": "ingest", "status": "ok"}\n'
        "not json\n"
        '{"step": "plan", "status": "ok"}\n',
        encoding="utf-8",
    )
    events, nxt, malformed = s.read_events("r1", 0)
    assert [e["step"] for e in events] == ["ingest", "plan"]
    assert nxt == 2 and malformed == 1
    assert s.read_events("r1", 2) == ([], 2, 1)


def test_list_skills_skips_directories_and_bad_json(tmp_path):
    (tmp_path / "en-vi").mkdir(parents=True)
    (tmp_path / "en-vi" / "general.json").write_text(
        json.dumps({"instruction": "i", "mean_score": 8.5, "domain": "general",
                    "src_lang": "en", "tgt_lang": "vi"}), encoding="utf-8")
    (tmp_path / "en-vi" / "broken.json").write_text("{not json", encoding="utf-8")
    (tmp_path / "en-vi" / "session_abc.json").write_text("{}", encoding="utf-8")
```

**Files:**
- Modify: `webui/runs.py`
- Modify: `tests/test_webui_runs.py`

**Interfaces:**
- Consumes: như Task 5.
- Produces (trên `RunManager`):
  - `status(run_id: str) -> RunRecord` — hoà giải trạng thái trên đĩa với thực tế tiến trình.
  - `stop(run_id: str) -> RunRecord` — dừng cả cây process; `raise KeyError` nếu lượt chạy
    không tồn tại, `raise RuntimeError("not running")` nếu đã kết thúc.
  - `events(run_id: str, after: int) -> tuple[list[dict], int, int]`
  - `has_events(run_id: str) -> bool`

**Ruling (Task 6):**

- `status()` **raise `KeyError`** cho `run_id` không tồn tại (đối xứng với `stop()`), và chỉ ghi
  lại `run.json` khi có gì đó thực sự đổi — poll mỗi ~700ms sẽ ghi lại file vô ích.
- Ghi chú trạng thái **cộng dồn** vào `note` thay vì ghi đè: một lượt có thể vừa mất file log vừa
  chết pid, và thông báo của lý do này không được nuốt lý do kia. `_note()` bỏ qua thông báo đã có
  nên poll lặp lại không làm chuỗi phình ra.
- `stop()` gọi `status()` **trước** khi kill: đó là chỗ duy nhất chặn việc kill một pid đã bị tái
  sử dụng (mục 11 của spec). Trạng thái chốt là `stopped` với `exit_code = null`.
- `pid_alive()` trên Windows **không** dùng `os.kill(pid, 0)`: trên Windows lời gọi đó *giết* tiến
  trình đích chứ không kiểm tra nó. Dùng `OpenProcess` + `GetExitCodeProcess` (259 = còn sống).
- `kill_tree()` dùng `taskkill /T /F` (Windows) hoặc `killpg` cả nhóm tiến trình (POSIX, nhóm do
  `start_new_session` tạo): kill mỗi pid cha sẽ để lại worker mồ côi đang giữ kết nối provider.
- `_reap()` chờ tối đa `STOP_TIMEOUT = 5s` rồi escalate một lần (POSIX `kill`), và **nuốt**
  `TimeoutExpired` một cách có chủ ý: dừng là best-effort, request không được treo vì một tiến
  trình cứng đầu — `stop()` vẫn chốt `stopped` và nói rõ điều đó trong `note`.

(inputs/glossary/skills) → Task 4, 8, 9; mục 7 (whitelist, bí mật, thứ tự ưu tiên) → Task 2
+ 3 + 8; mục 8 (an toàn) → Task 8; mục 9 (quyết định kỹ thuật) → Task 7, 8, 11; mục 10 (hình
ảnh) → Task 10; mục 11 (xử lý lỗi) → Task 6 (log vắng, pid chết), Task 8 (trùng tên), Task 9
(422, 409); mục 12 (test) → các bước 1 của mọi task; mục 13 (nghiệm thu) → Task 12. Không
phát hiện mục nào thiếu task.

**2. Quét từng bước.** Không còn dòng nào quyết định gì ("xử lý edge case", "thêm validate
phù hợp"). Các bước code chỉ nêu chữ ký và luật, không chép thân hàm — trừ bảng token CSS và
bảng ánh xạ env, vì đó là quyết định spec đã chốt chứ không phải code suy ra được.

**3. Nhất quán kiểu và tên.** `RunRecord` khai ở Task 4 và được Task 5, 6, 9 dùng với đúng
tên trường; `RunManager.start/status/stop/events` giữ nguyên chữ ký xuyên Task 5–6–9;
`Api.handle(method, path, query, body, headers) -> Response` khớp giữa Task 7, 8, 9;
`safe_child`, `is_secret`, `EDITABLE_KEYS`, `READONLY_KEYS` không đổi tên ở đâu.

Ba lỗi đã sửa trong lúc soát:

- **Mâu thuẫn thiết kế về `source`.** Task 2 ban đầu buộc `ConfigStore` nhận một dict
  "cấu hình hiệu lực" để tự phân loại `source`, nhưng `ConfigStore` chạy trong tiến trình
  server nên không thể biết một giá trị đến từ `os.environ` hay từ default — chỉ `probe.py`
  biết. Đã chuyển hẳn việc phân loại về Task 3 và thu `ConfigStore` về đúng việc đọc/ghi
  `.env` (`save`, `env_keys`); Task 9 giờ chỉ còn ghép hai nguồn thay vì tính lại.
- **Chữ ký sai.** Test Task 5 gọi `a.logs_dir()` trên `RunRecord`, trong khi interface ghi
  helper nằm ở `RunManager`. Đã chốt lại thành `RunManager.logs_dir(run_id)` và
  `RunManager.env_for(rec)`, và cập nhật cả hai chỗ gọi.
- **Giả định thư mục đã tồn tại.** Test "probe lỗi thì không khởi động gì" khẳng định
  `iterdir()` của `logs/webui` bằng rỗng, nhưng nếu chưa tạo gì thì thư mục đó không tồn
  tại và `iterdir()` sẽ ném `FileNotFoundError` — tức test sẽ đỏ vì lý do sai. Đã đổi thành
  hai khẳng định `not ... .exists()` cho cả `logs/webui` và `output/webui`.

**4. Review Focus.** Năm dòng ở đầu plan, mỗi dòng có test nằm trong bước 1 của task sở hữu.
Không có dòng nào mồ côi.

**5. Tỉ lệ.** Plan có 12 task; phần lớn độ dài là khối test bắt buộc và bảng token. Không có
bước nào chép thân hàm triển khai. Riêng Task 11 có phần kiểm tra thủ công bằng trình duyệt
mà repo không có harness để tự động hoá — đây là **hạn chế thật**, đã ghi rõ trong chính task
đó thay vì giả vờ rằng test đã phủ.
